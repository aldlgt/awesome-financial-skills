# Awesome Financial Skills

聚合、整理并定期更新“精而专”的金融 skill（研究方法、数据检索、知识库、指标查询、交易/定价模型等），按「研究类」和「数据类」组织，面向投研、信用与量化研究者。

目标
- 收集行业/产品/信用/交易研究类的专用 skill（可复用模板、Notebook、脚本、指标体系、方法论）。
- 收集数据类 skill（聚合搜索、指标查询、知识库/检索），并标注数据来源与更新频次。
- 使用 CI 自动发现候选项并通过 candidate PR 流程邀请人工审核与合入，保持库的“精而专”与可维护性。

目录（按你指定的分类）
- 研究类
  - 产业研究 — categories/research-industrial.md
  - 投资交易 — categories/research-trading.md
  - 信用研究 — categories/research-credit.md
  - 金融产品研究 — categories/research-products.md
- 数据类
  - 聚合搜索 — categories/data-aggregator.md
  - 指标查询 — categories/data-indicators.md
  - 知识库 — categories/data-knowledge.md

条目格式（示例）
- [skill-name](链接) — 一行简述（覆盖什么、为什么有用）。来源：xxx。最后更新时间：YYYY‑MM‑DD。维护者：@xxx（可选）

示例（占位）
- [semiconductor-domestic-substitute-skill](https://example.com) — 跟踪半导体设备国产替代的判别指标、替代进度与关键厂商清单；含数据源、报告模板与自动化监控脚本。来源：XXX；最后更新时间：2026-07-28。
- [pharma-kg-market-sizing-skill](https://example.com) — 创新药国内市场空间测算模板与数据链路（临床→上市→渗透假设），包含 Notebook 示例。来源：YYY；最后更新时间：2026-07-28。

贡献指南与质量门槛
- 本库追求“精而专”而非链接堆：条目应为方法/skill/模板/工具/高质量集合，且附带可验证的来源或示例。  
- 提交前请运行/检查格式，CI 会做基础校验。详见 CONTRIBUTING.md。
